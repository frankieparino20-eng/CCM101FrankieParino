# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, artificial intelligence, machine learning, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure with regions and zones. This allows organizations to deploy applications in different locations and improve performance and availability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

- Google Compute Engine – provides virtual machines for running applications.
- Google Cloud Storage – provides scalable object storage.
- Cloud SQL – provides managed relational databases.
- Google Kubernetes Engine (GKE) – provides managed Kubernetes clusters.

## Three Advantages

1. GCP provides strong artificial intelligence and machine learning services.
2. GCP provides scalable and reliable cloud infrastructure.
3. GCP has strong support for data analytics and Kubernetes.

## Typical Enterprise Use Cases

Organizations use GCP for artificial intelligence, machine learning, data analytics, application development, Kubernetes deployments, web applications, and large-scale data processing.
