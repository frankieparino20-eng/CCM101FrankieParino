# Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, security, artificial intelligence, and application development.

## Global Infrastructure

Azure has a global network of data centers organized into regions. Its infrastructure helps organizations deploy applications close to their users and maintain availability.

## Cloud Management Portal

The Azure Portal is a web-based interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

- Azure Virtual Machines – provides virtual servers for running applications.
- Azure Blob Storage – provides scalable object storage.
- Azure SQL Database – provides a managed relational database service.
- Microsoft Entra ID – provides identity and access management.

## Three Advantages

1. Azure provides strong integration with Microsoft technologies.
2. Azure offers a wide range of cloud services.
3. Azure supports scalability, security, and enterprise applications.

## Typical Enterprise Use Cases

Organizations use Azure for enterprise applications, virtual machines, databases, data analytics, Microsoft-based workloads, backup, and cloud migration.
